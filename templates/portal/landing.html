{# ------------------------------------------------------------------ Como funciona #}

Como funciona

Da rua ao painel em cinco passos

Cada pessoa da equipe trabalha com o próprio link. Você acompanha tudo por bairro e por equipe, sem planilhas soltas.

  1. {% icon "user-plus" "size-5" %}01

    Cadastre a equipe

    O administrador cria coordenadores e cabos eleitorais e define o que cada nível pode ver e fazer.

  2. {% icon "qr-code" "size-5" %}02

    Cada cabo recebe seu link e QR Code

    Link pessoal e cartaz com QR Code para imprimir ou compartilhar. Todo cadastro fica vinculado a quem divulgou.

  3. {% icon "smartphone" "size-5" %}03

    Apoiadores se cadastram

    Formulário rápido no celular: o CEP preenche o endereço e o consentimento LGPD é registrado com data e hora.

  4. {% icon "map-pinned" "size-5" %}04

    Acompanhe no mapa e nos dashboards

    Veja onde estão seus apoiadores por bairro, o desempenho de cada cabo e a evolução das metas.

  5. {% icon "message-square-text" "size-5" %}05

    Comunique-se pelo WhatsApp oficial

    Modelos de mensagem com variáveis e disparos segmentados somente para quem aceitou receber.

Segurança e conformidade

Feito para respeitar o apoiador e a legislação eleitoral

Comunicação política responsável protege a campanha. O E-Find nasceu com a LGPD e as resoluções do TSE como ponto de partida.

{% icon "lock" "size-5" %}

LGPD

Lei nº 13.709/2018

  • {% icon "shield-check" "mt-0.5 size-4 shrink-0 text-emerald-300" %} Consentimento explícito, com data, hora e texto aceito registrados
  • {% icon "shield-check" "mt-0.5 size-4 shrink-0 text-emerald-300" %} Aceite de mensagens de WhatsApp separado e opcional
  • {% icon "shield-check" "mt-0.5 size-4 shrink-0 text-emerald-300" %} Descadastro a qualquer momento — basta responder SAIR
  • {% icon "shield-check" "mt-0.5 size-4 shrink-0 text-emerald-300" %} Isolamento entre campanhas e acesso limitado pela hierarquia
  • {% icon "shield-check" "mt-0.5 size-4 shrink-0 text-emerald-300" %} Senhas protegidas por hash e credenciais de API criptografadas
  • {% icon "shield-check" "mt-0.5 size-4 shrink-0 text-emerald-300" %} Trilha de auditoria de acessos, alterações e exportações

Justiça Eleitoral

Lei das Eleições e resoluções do TSE

  • {% icon "badge-check" "mt-0.5 size-4 shrink-0 text-emerald-300" %} Somente a API oficial do WhatsApp (Meta) e parceiros oficiais
  • {% icon "badge-check" "mt-0.5 size-4 shrink-0 text-emerald-300" %} Envio apenas para apoiadores que consentiram — sem listas compradas
  • {% icon "badge-check" "mt-0.5 size-4 shrink-0 text-emerald-300" %} Mecanismo de descadastramento em toda comunicação (Lei nº 9.504/1997, art. 57-G)
  • {% icon "badge-check" "mt-0.5 size-4 shrink-0 text-emerald-300" %} Sem disparadores não oficiais, chips descartáveis ou WhatsApp Web automatizado
